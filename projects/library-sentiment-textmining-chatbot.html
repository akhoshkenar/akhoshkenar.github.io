1000+ Book Text Mining, Sentiment Analysis & Recommendation Chatbot

I analyzed a library of more than 1000 books and built a chatbot that suggests books for a user interested in a topic.

What I did

I created a text-mining pipeline for a library with more than 1000 books. I cleaned titles, descriptions, reviews, and other text, then converted the text into useful features.

I used sentiment analysis to measure positive and negative language. I also used topic modeling to find common themes and semantic representations to measure how close a book is to a user topic.

The chatbot accepts a simple question such as “I want a book about decision making and uncertainty.” It searches the library, combines topic fit, semantic similarity, and sentiment, and returns a ranked list such as a top-5 recommendation set.

How the model works

  1. Clean and tokenize the book corpus.
  2. Create TF-IDF, topics, and semantic embeddings.
  3. Score sentiment from reviews or descriptions.
  4. Index book vectors for semantic search.
  5. Combine similarity, topic, and sentiment scores in the chatbot ranking.
Positive result: The system turns a large text library into an easy conversation. A user can enter a topic in normal language and get focused book suggestions quickly.
