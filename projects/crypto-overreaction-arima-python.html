Cryptocurrency Overreaction Analysis with ARIMA

I analyzed overreaction in cryptocurrency markets using Bitcoin time-series data and ARIMA models in Python.

What I did

I prepared Bitcoin price and return data and looked for unusually large positive or negative moves. These events are possible overreaction points.

I used ARIMA models to describe the regular time-series structure. The model has autoregressive, differencing, and moving-average parts. ACF and PACF help select orders, while AIC and BIC help compare candidate models.

After estimating normal behavior, I studied what happens after large shocks. I measured whether returns reverse, continue, or return to the normal range during the event window.

How the model works

  1. Clean price data and calculate returns.
  2. Check stationarity and difference the series if needed.
  3. Fit ARIMA(p,d,q) candidates.
  4. Review ACF, PACF, AIC, BIC, and residuals.
  5. Detect extreme events and measure post-event reversal.
Positive result: The project combines classic time-series modeling with behavioral market analysis. It separates normal dynamics from unusual market reactions.
