Hospital Waste Vehicle Routing Optimization

I developed a mathematical vehicle-routing model for hospital waste collection and solved it with several heuristic methods in Python.

4heuristic layers
Capacityconstraints
Riskaware routing
Multi-routesolution

What I did

I modeled hospitals as waste pickup nodes and the treatment facility as the terminal destination. Each hospital has waste demand, and each truck has a limited capacity.

The mathematical model decides which hospital should be visited by each truck and in what order. The objective can minimize distance, time, operating cost, and exposure risk while keeping every route admissible.

For larger cases I used heuristic methods instead of relying only on exact optimization. The code uses local search ideas such as 2-opt, tabu search, simulated annealing, and a hybrid improvement stage.

How the model works

  1. Build distance, time, demand, and risk matrices.
  2. Create capacity and routing constraints.
  3. Generate an initial feasible route set.
  4. Improve routes with multiple heuristic methods.
  5. Compare convergence and final route quality.
Positive result: The final model turns a complex routing problem into clear truck routes. It can reduce unnecessary travel while respecting capacity and safety rules.
