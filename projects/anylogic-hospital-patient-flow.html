Comprehensive Hospital Patient Flow Simulation

I built a large AnyLogic hospital model for patient flow, department design, resources, queues, and capacity planning.

What I did

I created a large hospital simulation with areas such as emergency, triage, operating rooms, ICU, imaging, laboratory, wards, recovery, and discharge. Patients move between these areas based on their condition and required service.

I created AnyLogic process modules and used blocks such as Source, Queue, Service, Delay, SelectOutput, MoveTo, and Sink. I also used custom Java code for routing, resource logic, priorities, and special patient rules.

The model can test different hospital designs before making a real change. It shows how beds, doctors, nurses, rooms, and queues interact underneath the visible patient flow.

How the model works

  1. Build patient and resource agent types.
  2. Create process modules for hospital departments.
  3. Add Java logic for routing and priority rules.
  4. Run patient arrivals and resource competition.
  5. Compare layouts, staffing, beds, and capacity scenarios.
Positive result: This is a comprehensive hospital digital-twin style model. It makes bottlenecks visible and helps management test new designs with low risk.
