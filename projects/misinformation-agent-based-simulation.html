Agent-Based Misinformation Diffusion & Control

I used agent-based simulation to study how misinformation spreads in social media and how control policies can slow it.

What I did

I modeled social-media users as agents connected in a network. Each agent can be unaware, exposed, sharing, or corrected. A person can change state after contact with other agents.

The model follows cascades over time. It can show when misinformation grows fast, where it moves between communities, and which agents have a large effect on the final cascade.

I tested control actions such as fact checking, sharing friction, and targeted intervention. The goal is to reduce harmful spread while keeping the intervention cost reasonable.

How the model works

  1. Create the social network and agent states.
  2. Set sharing, correction, and exposure probabilities.
  3. Run repeated diffusion simulations.
  4. Apply different control policies.
  5. Compare cascade size, peak time, correction reach, and intervention cost.
Positive result: The simulation makes a difficult social process visible. It shows how small policy changes can change the size and speed of a misinformation cascade.
