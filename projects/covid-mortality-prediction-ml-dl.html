COVID Patient Mortality Prediction with ML/DL

I built a Python pipeline to predict mortality risk for COVID patients from patient features using machine-learning and deep-learning models.

4model families
5-foldcross-validation
6+evaluation measures
Patientrisk score

What I did

I prepared patient features such as age, laboratory values, vital signs, comorbidity information, and other available clinical variables. I cleaned missing values and created model-ready features in Python.

The workflow compares several model families, including logistic regression, tree-based models, boosting, and neural networks. Cross-validation is used so the comparison is more stable than one train-test split.

The final output is a patient risk probability. I also created graphs for ROC curves, confusion matrices, feature importance, and model comparison.

How the model works

  1. Clean patient-level data and missing values.
  2. Normalize / encode model inputs.
  3. Train four model families.
  4. Use five-fold cross-validation in the portfolio workflow.
  5. Compare discrimination, error, and calibration measures.
Positive result: The project is an end-to-end clinical ML pipeline. It connects Python coding, model comparison, explainability, and a simple patient-level risk output.
Metric note: No audited clinical accuracy was supplied for this website package. The page therefore names the evaluation measures but does not claim a final clinical accuracy value.
